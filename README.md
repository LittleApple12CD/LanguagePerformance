# LanguagePerformance
- 一个用于对比多种语言的性能差距的项目。项目包括 C++ SDL3, C++ SFML, C++ raylib, Rust Macroquad, Rust Bevy, Java Swing, Java JavaFX, Java LibGDX, Go Ebiten, Python Pygame, Python Pyglet, HTML5 多个语言实现 （注意：此项目并非绝对准确）<br>
- A project designed to compare the performance gap across multiple programming languages. This includes implementations across multiple languages and frameworks, such as C++ (SDL3, SFML, raylib), Rust (Macroquad, Bevy), Java (Swing, JavaFX, LibGDX), Go (Ebiten), Python (Pygame, Pyglet), and HTML5. (Note: This project is not absolutely accurate.)

# How to use 如何使用
- 从 [GitHub Releases](https://github.com/LittleApple12CD/LanguagePerformance/releases) 下载发布包，解压ZIP文件，然后通过运行子目录的EXE程序或BAT脚本来手动测试
- Download the release package from [GitHub Releases](https://github.com/LittleApple12CD/LanguagePerformance/releases), extract the ZIP file, and run the EXE programs or BAT scripts in the subdirectories for manual testing.

- **Python** : Python 3.12, Pygame, Pyglet, Numpy, Numba
- **Rust** : Rustup 1.29, Cargo 1.97, Macroquad, Bevy
- **Go** : Go 1.21.5, Ebiten
